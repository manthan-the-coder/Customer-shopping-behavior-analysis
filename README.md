# Customer-shopping-behavior-analysis
End-to-end customer shopping behavior analysis using Python, PostgreSQL and Power BI.

## Project Overview

This project analyzes customer shopping behavior to identify purchasing patterns,
customer preferences, and business insights.

The project follows an end-to-end data analytics workflow:

Python → Exploratory Data Analysis → PostgreSQL → Business Analysis → Power BI

## Objectives

- Analyze customer purchasing behavior
- Identify important customer segments
- Analyze revenue and purchase patterns
- Study discounts, subscriptions and shipping methods
- Identify top-performing products
- Generate actionable business insights

## Tools & Technologies

- Python
- Pandas
- Jupyter Notebook
- PostgreSQL
- pgAdmin 4
- SQL
- Power BI

## Dataset

The dataset contains customer shopping information including:

- Customer ID
- Age
- Gender
- Item Purchased
- Category
- Purchase Amount
- Location
- Size
- Color
- Season
- Review Rating
- Subscription Status
- Shipping Type
- Discount Applied
- Promo Code Used
- Previous Purchases
- Payment Method
- Frequency of Purchases

## Project Workflow

### 1. Data Preparation

The dataset was loaded and inspected using Python.

Missing values and data quality were checked and appropriate preprocessing
was performed.

### 2. Exploratory Data Analysis

Python was used to analyze:

- Customer demographics
- Purchase behavior
- Product categories
- Revenue patterns
- Ratings
- Discounts
- Subscription behavior
- Shipping methods

### 3. PostgreSQL Business Analysis

The cleaned dataset was loaded into PostgreSQL.

SQL queries were used to answer business questions such as:

- Revenue by gender
- Discount usage and spending
- Top-rated products
- Shipping method comparison
- Subscriber vs non-subscriber behavior
- Products with high discount usage
- Category-level product performance

### 4. Power BI Dashboard

A Power BI dashboard was created to provide an interactive view of
customer shopping behavior and business performance.

## Key Insights

The analysis identified several useful customer and purchasing patterns.

The detailed findings are available in the project report.
